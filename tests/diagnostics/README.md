# Structured diagnostic regression

Run the absolute central test runner with the fresh supported developer Python
using `-I -B --layer diagnostics`, both explicit `--shell-path` values and a new
external `--report` path. The targeted route needs no shell-tool installation;
both actual PS5.1 and PS7 hosts are required. This is the eighth full stage.

AC-030 checks 21 actual CLI requests and two controlled callable injections:
flat/no-outline, unusable destinations, absent direct Level 2 children, zero-page
inputs in every mode, empty/corrupt/truncated/missing input, invalid manual/mode,
malformed outline, existing output, missing/extra arguments, rejected shared plan, first-write failure,
and three successful mode controls. Every rejection carries its distinct explicit
JSON category, nonzero process status, zero newly written files and no automatic
fallback. Successful controls reopen actual outputs and verify complete physical
page identities, filename/order/range and execution-result parity. Existing files,
inputs and synthetic neighbors remain unchanged.
The actual Level 1 control uses a Unicode source path and Chinese/å bookmark
titles; literal filenames and decoded CLI writing messages must survive intact.

AC-031 dot-sources the shipped pure diagnostic helper in each fresh actual host.
Every valid requested-mode engine receipt is parsed and fed to the real category
handler. Eleven choices exercise pending/cancel/retry/invalid decisions, exact
tokens, case/whitespace normalization and available manual/Level 1 alternatives.
No Level 2 result is mislabeled as a document without outlines. Eighteen malformed,
missing, duplicated, inconsistent or invalid-request-mode protocols reject.

Each host also exercises the production native quoting helper with empty strings,
spaces, quotes, Unicode, trailing slashes and shell-like data. An AST load isolates
the authored `Run-PythonSplitter` function from top-level application startup. A
run-owned synthetic child sends 200K characters on both streams, literal argument
echoes and a structured final failure. The actual function must drain/log both
streams, retain the final category and use the explicit fresh Python via controlled
PATH. This probe writes no chapter files and touches no Documents content.

Reports include every actual case/choice/host/protocol/native observation, runtime
and source/input hashes, safe import, immutable original guards and owned cleanup.
The central validator refuses missing or malformed promised evidence. Historic
fixture/oracle/extraction inputs and earlier receipts stay unchanged. Full app
cancel/retry/batch interaction, Explorer, Calibre, complete output transactions
and the extracted release package remain separate checks.
