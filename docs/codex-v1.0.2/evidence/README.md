# Evidence records

Create new task/native/release evidence here during actual work. Templates and synthetic policy/incident cases are NOT evidence. Never modify v1.0.0/v1.0.1 historical reports to make them look current.

For each PASS link an actual evidence file under this directory, with source/ZIP/runtime/machine/command/expected/actual details appropriate to the case. Store raw sensitive logs privately and commit only reviewed redacted summaries. Missing execution stays NOT_RUN/BLOCKED. Hashes bind bytes; they do not establish test truth.
