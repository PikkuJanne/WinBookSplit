## Required acceptance

**V102-AC-019 — 3.15-only automatic discovery.** Without override/venv, trusted regular 3.15 is discovered and selected automatically; installation is never triggered during processing discovery.

**V102-AC-020 — Broken optional launcher fallback.** A legacy/manager py listing failure like Unknown option -0 is recorded but a valid direct 3.15 candidate still succeeds.

**V102-AC-021 — Authoritative existing environment.** Healthy accepted 3.13/3.14 venv remains selected despite PATH 3.15; identity/diagnostics name it accurately; setup is a no-change no-op.

**V102-AC-022 — Stale environment preserved.** Rejected/broken .venv remains authoritative and is not deleted or silently bypassed; failure names the actual venv version and specific reason.

**V102-AC-023 — Explicit repair to 3.15.** Valid 3.15 base plus Repair creates working new venv while retaining a unique old backup; rollback/error behavior is honest and non-destructive.

**V102-AC-024 — Trust and override preservation.** Invalid explicit selection, shadow modules, unsafe aliases/CWD sources and untrusted package origin fail as before; no any-python fallback or auto-download.
