## Acceptance

- **V101-AC-025:** A bare compatible Python can create the app environment and install the reviewed runtime lock without global pypdf.
- **V101-AC-026:** A healthy existing environment validates without replacement or unnecessary package downloads.
- **V101-AC-027:** A broken/unapproved existing environment is preserved by default and has an actionable explicit repair route.
- **V101-AC-028:** Explicit repair preserves/restores the original environment on failure; unrelated files are not removed.
- **V101-AC-029:** Setup does not promote a relocated completed venv; the final environment works from its actual final path.
- **V101-AC-030:** Online/offline installs enforce reviewed hashes/binary packages; a hash mismatch or absent wheel fails without unsafe fallback.
- **V101-AC-031:** Check mode and normal processing never install, create environments or change global packages/PATH/policy.
- **V101-AC-032:** Two setups, interruption, locked files and unwritable/reparse paths are handled without deleting user-owned content.
- **V101-AC-033:** NonInteractive never prompts; missing prerequisites return precise errors. No Python/Calibre auto-install or elevation is hidden in setup.
