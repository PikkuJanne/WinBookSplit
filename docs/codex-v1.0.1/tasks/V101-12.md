# V101-12 — Review, integrate and freeze the release source

Milestone: M4. Prerequisites: V101-11

## Read

- [RELEASE_RUNBOOK.md](../RELEASE_RUNBOOK.md)
- [GITHUB_SYNC.md](../GITHUB_SYNC.md)

## Work

Perform focused code/security review and regression/CI checks, using a separate review context when available but not falsely claiming independent audit. Resolve blockers. Merge normally and select exact reviewed release source R. Build/inspect the three accepted candidate assets with the existing builder and manifest, outside the checkout. Freeze artifact identities and prove they are from R. Do not tag or publish while final native acceptance is still pending.

## Acceptance

- **V101-AC-064:** Changed policy/discovery/setup/native handling reviewed; critical/security/correctness blockers resolved with actual test evidence.
- **V101-AC-065:** R is a reviewed integrated commit reachable from main with passing required checks, not a stale unmerged branch.
- **V101-AC-066:** ZIP/manifest/checksums and member allowlist are audited against R; no uncommitted bytes or manual ZIP edits.
- **V101-AC-067:** Exact source R and asset hashes fixed before final native runs; comparison of different build-toolchains is not required.

## Checkpoint and continuation
Record actual commands, source/package identity, outcomes and limitations in a brief redacted evidence file under `evidence/`. Update TASKS/ACCEPTANCE_CASES/STATUS/NEXT_SESSION. Commit only intended files, push normally and verify clean HEAD against the freshly queried live remote branch. A prior receipt does not certify a later commit. Then continue the next ready task rather than asking the owner to approve another ordinary milestone.

No private documents, fabricated evidence, unapproved infrastructure or destructive Git commands. Human testing is governed by HUMAN_TESTING.md, not the old v1.0.0 checklist. If this task is genuinely blocked, identify the exact dependency and complete independent work first.
