## Acceptance

- **AC-013: Explicit first page alone.** N=10; starts=1. Expected: Exactly [0,10), one-section notice; writer produces one valid 10-page output.
- **AC-014: Explicit and implicit first page.** N=10; starts=1,4,7 then 4,7. Expected: Both produce [0,3),[3,6),[6,10); no omitted first pages.
- **AC-015: Sort duplicate and leading-zero inputs.** N=10; starts=7, 04,4, 1. Expected: Validate then normalize to 1,4,7 with notices; no duplicate/empty slices.
- **AC-016: Empty input and tokens.** Try empty, whitespace, comma, 1,,4, 1, and ,4. Expected: All fail clearly before output; no whole-file implicit copy.
- **AC-017: Unsupported syntax and mixed tokens.** Try abc; 1-4; 1,abc,7; +4; -1; 1.5; non-ASCII digit glyphs. Expected: All rejected entirely; no token silently filtered.
- **AC-018: Bounds and final page.** N=10: reject 0, 11, 0,999, huge integer; accept 10. Expected: Invalid lists fail; valid 10 yields [0,9),[9,10), preserving final one-page segment.
