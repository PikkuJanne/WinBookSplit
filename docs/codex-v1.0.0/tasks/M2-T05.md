## Work

1. Use a small tested direct-executable argument-marshalling path compatible with PS5.1 and PS7.
2. Drain both streams concurrently to EOF including fast exit, blank lines, no-newline tail and heavy stderr.
3. Set child/output UTF-8 explicitly and bound buffers; close handles reliably.
4. Record real host tests and review/merge the milestone without mixing in a new process framework.

## Deliverables

- Unicode/argument/flood tests
- M2 merged checkpoint

## Acceptance

- **AC-046: Dual stream flood.** Child writes large stderr before/stdout bursts and exits, both hosts. Expected: No deadlock; bounded diagnostics retained; child result surfaced correctly.
- **AC-047: Fast exit and output tail.** Child exits immediately; blank lines; no trailing newline; final stderr message. Expected: Both streams drained fully without loop skipping/tail loss; outcome preserved.
- **AC-048: Unicode encoding.** Paths/bookmarks/output include Janne, ääkköset, Größe and non-Latin characters in both hosts. Expected: UTF-8 communication/logs round-trip correctly; no UnicodeEncodeError or mojibake-induced filenames.
- **AC-049: Argument injection boundary.** Controlled files contain &, %, !, brackets and spaces; titles contain shell/Python-looking text. Expected: Literal data only; no extra command executed or injected engine source; intended file processed.
